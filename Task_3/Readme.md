### Как этапы реализации соотносятся с бизнес-целями

| Бизнес-цель | Какие меры в плане этому способствуют |
| --- | --- |
| Ускорение принятия управленческих решений | Создание отдельного аналитического хранилища, запуск первых витрин данных, внедрение портала для работы с отчётами |
| Ускоренный вывод новых продуктов и направлений | Выделение доменов, внедрение API-шлюза, организация интеграционной прослойки |
| Уменьшение привязки к существующему DWH | Перевод отчётности на новые витрины, прекращение размещения новой логики в старом хранилище |
| Обеспечение безопасности медицинской и финансовой информации | Внедрение каталога данных, организация системы аудита, разграничение доменов |
| Подготовка инфраструктуры к миграции в облако | Использование Terraform для кодификации инфраструктуры, создание изолированных сред, настройка системы мониторинга |

## Логика предложенной последовательности

На начальном этапе необходимо согласовать доменные границы и развернуть базовую аналитическую платформу. Если попытаться сразу приступить к полной замене хранилища или тотальной модернизации интерфейсов, проект окажется излишне масштабным и сопряжённым с высокими рисками.

После того как первые витрины данных заработают, можно переходить к подключению предметных доменов и запуску портала самообслуживания для пользователей. А на финальной стадии — ближе к завершению года — целесообразно интегрировать партнёрские сервисы и начать поэтапное сокращение роли устаревших систем.
